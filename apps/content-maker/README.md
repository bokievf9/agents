# content-maker: Контент-мейкер Fir Tech (этап 1, текст)

Голова отдела маркетинга (`../../../COMPANY.md`, план: `../docs/content-plan-2026-12.md`). Каждый понедельник в 09:00
(`TZ`, `PACK_CRON`) готовит пакет недели и присылает владельцу на одобрение. Видео, озвучка и публикация: этап 2.

## Что делает
Пакет недели: 3 сценария клипов (20-40 с, хук в первую секунду, сцены с озвучкой и субтитром, CTA на firtech.pro)
и 1 карусель (6-8 слайдов) плюс подписи и хэштеги для Instagram, TikTok и Shorts. Темы идут по 8 направлениям услуг
(`src/directions.ts`, цены зеркалят `firtech/src/lib/directions.ts`) и 4 ракурсам (как работает, цена, было-стало, показ).
История тем в SQLite: тема не повторяется 6 недель. Выход: клипы вт, чт, сб, карусель ср.

Промпты лежат в `prompts/*.md` (русский, голос бренда). Ответ модели: строгий JSON через `tryJson`, проверка схемой
(zod), затем проверка тона (`src/lint.ts`: обороты «не X, а Y», перечисления отсутствий, стоковые фразы, длинное тире,
эмодзи, обещания цифр, чужие цены, нет firtech.pro). Найденное модель исправляет один раз, остаток уходит владельцу
предупреждением над материалом. Без ключа LLM пакет не создаётся, бот сообщает об этом.

## Команды (только `OWNER_TELEGRAM_ID`, личный чат)
- `/pack`: сгенерировать пакет сейчас (ближайшая неделя с понедельника).
- `/topic <тема>`: один материал; `/topic карусель <тема>`: карусель.
- `/queue`: что одобрено и ждёт выхода. `/stats`: одобрено, отклонено, правки, вторые версии.
- `/skip`: отменить ожидание комментария после отклонения.

## Как работает одобрение
Каждый материал отдельным сообщением «материал N из 4» с кнопками Одобрить / Править / Отклонить (очередь одобрений
ядра, тип `content_item`, уровень 0 и `locked`: счётчик доверия не включает автопубликацию). Править: следующее
сообщение заменяет весь текст. Одобренный материал сохраняется как `ready`: по строке на платформу (клип: Instagram,
TikTok, Shorts; карусель: Instagram) с типом, текстом и плановой датой (таблица `ready`). Отклонённый: бот просит
комментарий, делает вторую версию один раз с учётом комментария; второй отказ окончательный.

## Переменные
`CONTENT_BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `TZ` (Asia/Tashkent), `DATA_DIR`, `PACK_CRON` (`0 9 * * 1`), `LLM_BASE_URL`,
`LLM_API_KEY`, `LLM_MODEL_SMART` (`auto`). См. `.env.example`.

## Запуск
`pnpm --filter content-maker dev` (`.env.local`). Docker: `apps/content-maker/Dockerfile`, сервис `content-maker` в
`compose.yaml`, образ `agents-content-maker` в CI, данные `/opt/fir-agents/data/content-maker`.

## Этап 2
Remotion: рендер клипа из сцен (субтитры по строкам), TTS (синтез голоса), Whisper для сверки и тайминга субтитров,
рендер слайдов карусели. Голова Публикатор читает таблицу `ready` и публикует по плановой дате (статус `published`).

# Polly: учитель языков (этап 1)

Личный агент владельца на ядре `@fir/core`. Telegram-бот, отвечает только `OWNER_TELEGRAM_ID`, остальных молча
игнорирует. Цель владельца: говорить в поездках и в быту. Первый язык: китайский (упрощённые иероглифы, пиньинь, тоны),
уровень с нуля. Этап 1: текст. Голос (Whisper, edge-tts), испанский и турецкий, календарь Dono не входят.

## Запуск
```
cp apps/polly/.env.example apps/polly/.env.local   # POLLY_BOT_TOKEN (отдельный бот), OWNER_TELEGRAM_ID
pnpm --filter polly dev
```
Данные: SQLite `polly.db` в `DATA_DIR` (по умолчанию `data/polly/`, не в git). Без ключа LLM бот работает в режиме
«LLM off»: уроки, карточки, тоны и тест уровня целиком из файлов, не работает только `/talk`.

## Что умеет
- `/start`: тест уровня (3 вопроса про тоны, 10 слов, 3 фразы) или «с нуля»; профиль: язык, уровень, цель, минуты в день
  (30), время урока (`/time 19:30`).
- `/lesson`: урок дня. Приветствие, 3 новых слова (пиньинь, тоны, перевод, пример), мини-диалог по ситуации, 3 вопроса
  проверки. Кнопки: «Дальше», «Повтори», «Объясни по-русски». В конце слова и помеченные фразы диалога становятся карточками,
  растёт серия дней.
- `/review`: карточки по FSRS-4.5 (`src/fsrs.ts`, веса по умолчанию, оценки Снова / Трудно / Хорошо / Легко). Карточка с
  «Снова» возвращается в той же сессии, остальные получают срок на начало местного дня.
- `/tones`: 5 вопросов на тоны (минимальные пары из `tones.yaml`).
- `/talk`: свободный разговор через LLM (только с ключом), `/stop` выйти. История в SQLite.
- Напоминание об уроке в `lessonTime` по часовому поясу профиля, один раз в день и только если урок ещё не пройден.
  Отчёт в воскресенье в `WEEKLY_REPORT_AT`: минуты (сумма пауз между нажатиями короче 5 минут), уроки, ответы на
  карточки, слова в активе (повторены и помнятся 2 дня и дольше), серия.
- Голосовые принимаются и откладываются в таблицу `voice_queue` с ответом «голос подключу на этапе 2».

## Контент: `content/zh/`
Всё в YAML, код не знает ни одного слова. При старте файлы проверяются (`src/content.ts`): повторяющееся слово, слово
урока без примера или пояснения, неверный номер ответа останавливают запуск.
- `words-<тема>.yaml`: `topic`, `title`, `words: [{h, p, r, n?, e?}]`. `h` иероглифы, `p` пиньинь с тонами, `r` русский
  перевод, `n` пояснение по-русски («Объясни»), `e` пример `{h, p, r}`. Слова уроков обязаны иметь `n` и `e`.
  Сейчас 9 тем, 318 слов.
- `lessons.yaml`: 14 дней. День: `day`, `title`, `situation` (знакомство, кафе, такси, магазин, отель, дорога,
  вежливость), `intro`, `tone_tip`, `words` (3 иероглифа из словаря), `dialog {title, note, lines[{who,h,p,r,card?}]}`,
  `quiz` (3 вопроса: `q`, `o` варианты, `a` номер верного с нуля, `why?`). `card: true` делает фразу карточкой.
- `tones.yaml`: наборы слогов в четырёх тонах и иероглифы к ним. `placement.yaml`: вопросы теста уровня.

## Как добавить язык
1. `content/<код>/` с теми же файлами (`words-*.yaml`, `lessons.yaml`, `tones.yaml` или свой тренажёр, `placement.yaml`).
2. В `src/content.ts` расширить тип `language` (сейчас `'zh'`) и в `src/store.ts` поле `language` профиля.
3. Тон и пиньинь специфичны для китайского: для испанского и турецкого заменить `tones.yaml` на свой тренажёр
   (ударение, гармония гласных) и пока скрыть `/tones`.
4. Выбор языка в профиле и `/start` (этап 2 и дальше).

# База знаний Fir Tech

Файлы, которые читают и люди, и агенты. Меняется только коммитом (строителем или владельцем), агенты HQ сами сюда не пишут.

- `playbooks/`: как мы делаем повторяющиеся вещи (проект от КП до сдачи, деплой, ревью). Один файл на тему, заголовок `# ` первой строкой: по заголовкам ищет `/kb`.
- `playbooks/ig-*.md`: подробные темы по Instagram (рилсы, подписи, карусели и истории, человеческий текст, вирусный разбор, аудит, профиль, комментарии и директ, план). Конспект навыков владельца, лицензия MIT, подробности в `docs/playbooks.md`.
- `hooks.json` (26 формул хука, RU и EN), `profile-rubric.json` (рубрика профиля, 100 баллов), `voice.md` (голос Fir Tech): данные для инструментов `text.*` и Контент-мейкера.
- `lessons/`: уроки из закрытых проектов по месяцам, `YYYY-MM.md`. Записываются командой `/lesson <проект>: <урок>` в таблицу `kb_lessons`, а раз в неделю (воскресенье 19:00) HQ создаёт builder-задачу «Обновить knowledge/lessons», строитель коммитит новые записи.
- Шаблоны агентов и инструкции головы лежат в `apps/hq/instructions/`, здесь только знания, не конфигурация.

Правила записей: факт и вывод в одну-две строки, без клиентских имён и контактов, без секретов, без цен конкретных клиентов.

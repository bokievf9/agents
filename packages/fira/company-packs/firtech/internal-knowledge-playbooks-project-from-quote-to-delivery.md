# Проект от КП до сдачи

1. КП одобрено или оплачено: `/project <клиент>: <что делаем>`. Голова производства создаёт проект и этапы (бриф, прототип, сдача, оплата) с целевыми датами.
2. Короткое ТЗ приходит на одобрение. Цену и сроки в нём ставит владелец (`[цена]`, `[срок]`).
3. После одобрения ТЗ строительные этапы (прототип, сдача) уходят в GitHub issues для Claude Code. Результат: ссылка на ветку или PR последним комментарием.
4. Ревью: на результат создаётся задача «Ревью: ...» (безопасность, тесты, секреты, миграции).
5. Сдача: задача «Деплой: ...» с чек-листом (CI, окружение, DNS, TLS, health) и запрос отделу сопровождения добавить адрес в мониторинг.
6. Акт сдачи: `/doc акт <клиент>`. После закрытия проекта: `/lesson <проект>: <урок>`.

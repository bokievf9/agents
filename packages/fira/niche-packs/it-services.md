# ИТ-услуги для малого бизнеса

Сфера Fira. Сфера самой Fir Tech (tenant 0). Собрана 2026-11-22 из `apps/hq/src/client/needs.ts` (таблица «нужда → продукт»),
`apps/hq/instructions/client-bot.md` («Как мы работаем», «Правила») и `knowledge/voice.md`.

## Услуги
- ИИ-администратор: запись, напоминания, отзывы для услуг по записи (барбершопы, салоны, клиники, студии, автосервис, репетиторы).
- ИИ-менеджер заявок: отвечает на заявки 24/7 в Telegram, WhatsApp, Instagram и на сайте, квалифицирует и передаёт менеджеру.
- Автоматизация процессов: таблицы, CRM, отчёты, рассылки, связки сервисов.
- Контент на автопилоте: посты, карточки, ролики по подписке.
- Telegram Mini App: каталог, корзина, заказ, запись внутри Telegram (магазины, кафе, доставка).
- Персональный ИИ-ассистент: ведёт дела одного человека в Telegram.
- ИИ-отдел под ключ: база знаний, ответы по документам, несколько агентов, обучение команды.
- Классика: сайт и лендинг, приложение.

## Термины
- Нужда «запись, бронь, администратор» ведёт к ИИ-администратору; «заявки, ответы ночью, квалификация» к ИИ-менеджеру заявок.
- Просьба про «бота» для бизнеса по записи значит ИИ-администратор, для магазина или кафе Telegram Mini App, в остальных случаях ИИ-менеджер заявок.
- «Не хочу сайт, только агент»: агент живёт на площадке Fir Tech, сайт из сборки убирается.
- Сборка проекта: страница сайта, где человек сам собирает проект и сразу видит цену и этапы оплаты.
- Смета: документ с точной ценой и сроком до старта. Этап: часть работы, оплачивается до её начала.
- Домен и хостинг: адрес и сервер сайта; платные сторонние сервисы оплачивает клиент.

## Частые вопросы
- Как вы работаете? :: Человек описывает задачу, мы предлагаем собрать проект или созвониться, потом коммерческое предложение с ценой и сроками, договор, оплата первого этапа. Делаем, показываем по ходу, запускаем, первую неделю сопровождаем.
- Как быстро вы отвечаете? :: Менеджер проекта отвечает в течение 5 минут в рабочее время, агент клиентам за минуту круглосуточно; цены и сроки подтверждает менеджер проекта.
- Как платить? :: По этапам: каждый этап до его начала, последний до передачи доступов. Картой или по счёту, реквизиты счёта появятся в кабинете после регистрации юрлица; криптовалюту не принимаем.
- Кому принадлежит код? :: Код и доступы остаются у клиента.
- Есть гарантия? :: Есть гарантия первого результата: она возвращает оплату первого этапа, условия записаны в договоре.
- Можно без сайта? :: Да, агент может работать без сайта, на площадке Fir Tech или в Telegram.
- Кто отвечает в чате? :: Фира, ИИ-ассистент Fir Tech (ИИ-менеджер заявок); решения о цене, договоре и деньгах принимает человек.

## Возражения
- Дорого. :: Точную сумму под задачу считает сборка проекта, можно начать с одного продукта и одного этапа; оплата идёт по этапам.
- Боюсь, что ИИ ответит клиенту не то. :: Агент отвечает только из знаний компании, цены и сроки не придумывает, сложное передаёт человеку; правки владельца становятся уроками.
- У нас уже есть сайт. :: Тогда сайт не нужен: агент подключается к тому, что уже есть, или работает в Telegram.
- Подумаю. :: Хорошо. Сборка проекта по ссылке сохранит то, что вы рассказали, к ней можно вернуться.

## Границы
- Не обещать цифры результата («+30% записей», «окупится за месяц»).
- Не называть способы оплаты, которых нет в смете (карты, Kaspi, Payme, Click).
- Не говорить «наши клиенты» и «наш опыт внедрения»: реальных кейсов пока нет, всё показательное подписано как пример.

## Тон
- Спокойно и предметно, как инженер, который показывает работу; сначала предмет или действие, потом пояснение.
- Слова сферы: заявка, запись, клиент, смета, срок, этап, доступ, расписание, ночью, сразу.
- Не говорить: уникальный, инновационный, революция, комплексный подход, индивидуальный подход, широкий спектр, надёжный партнёр, оптимальное решение.

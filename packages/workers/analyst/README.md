# @fir/worker-analyst: Аналитик (этап 1)

Исполнитель отдела маркетинга. Рутина `marketing-analyst-weekly`, понедельник 08:00 по Ташкенту. Только читает БД HQ и,
если заданы ключи, статистику канала YouTube. Результат: один отчёт на русском с пятью числами и тремя рекомендациями;
голова кладёт его в журнал задачи, и он попадает в утреннюю сводку Директора (отчёт, созданный в 08:00 после сводки,
виден в сводке следующего дня; команда `/tasks marketing` показывает его сразу).

## Пять чисел (за прошедшую неделю, пн-вс)
1. Одобрено материалов на неделю, платформ (`cm_ready` со статусом `ready` или `published` и плановой датой в неделе).
2. Опубликовано вручную по платформам (`pb_posts.published_at`, кнопка «Опубликовано» Публикатора).
3. Лидов, и неделей ранее. Лид это верхнеуровневая задача отдела `sales` с тегом `lead`, с `meta.action = "lead"` или с
   заголовком, начинающимся со слова «Лид». Отделу продаж нужно ставить один из этих признаков.
4. Расходы на ИИ по таблице `costs` за неделю.
5. Подписчики YouTube и прирост к прошлому снимку (`an_snapshots`).
Дополнительно строкой: воронка разведчика по статусам, если есть таблица `prospects` (или `pr_prospects`, `pr_cards`) с колонкой
`status`. Чего нет в данных, помечено «нет данных», числа не придумываются.

Три рекомендации пишет модель (strict JSON, только по числам); без модели работают правила (`fallbackRecommendations`).

## YouTube (необязательно)
`YOUTUBE_API_KEY` (тот же ключ YouTube Data API v3, что у Трендвотчера) и `YOUTUBE_CHANNEL_ID` (страница канала, «Настройки»,
«Расширенные настройки», идентификатор вида `UC...`). Берётся `channels.list part=statistics`.

## Этап 2: Instagram и TikTok
Инсайты Instagram (охват, показы, сохранения) требуют: профессиональный аккаунт, привязанный к Facebook Page, приложение на
developers.facebook.com с Instagram Graph API, разрешения `instagram_manage_insights`, `pages_show_list`, долгоживущий токен.
Статистика TikTok требует аккаунт на developers.tiktok.com и приложение с Display API (`user.info.stats`, `video.list`) и
OAuth владельца. Пока в отчёте стоит строка «статистики пока нет (этап 2)».

Тесты: `pnpm --filter @fir/worker-analyst test`.

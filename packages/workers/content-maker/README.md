# @fir/worker-content-maker: Контент-мейкер (исполнитель отдела маркетинга)

Бывший `apps/content-maker`, из которого убраны бот и крон: теперь это исполнитель под головой Маркетинга
(`apps/hq/src/heads/marketing.ts`, схема `../../../docs/architecture-hq.md`). Логика и тесты сохранены.

## Контракт исполнителя
`ContentMakerWorker` реализует `Worker` из `@fir/hq`: `run(task, ctx)` и необязательный `plan(task, ctx)`.
`ctx` даёт `llm` (со счётом расходов), `db` (общая SQLite HQ, свои таблицы с префиксом `cm_`), `requestApproval`
(голова придержит предложение до своей проверки, потом оно уйдёт в пачку Директора) и `log`.
Исполнитель сам ничего наружу не пишет.

Действия задачи (`task.meta.action`):
- `pack`: пакет недели для всей страницы Instagram. `plan` создаёт пакет и по черновику на материал: 7 рилсов (`clip`, по одному в день),
  3 поста (пн, ср, пт), 2 карусели (вт, пт), 5 историй (пн, вт, ср, пт, сб). Число карусели в неделю `floor(w*r) - floor((w-1)*r)`,
  поэтому дробное `r` (0.5) работает как раньше. Темы рилсов и каруселей: 48 тем «направление x ракурс» (`topics.ts`, без повтора 6 недель);
  посты и истории: формат (кейс-сценарий «до и после» с пометкой «Пример сценария», разбор ошибки, чеклист, FAQ) на продукт или нишу,
  продукты и ниши чередуются (`FORMAT_TOPICS`, 4 x 65). Цифры дня нет. Каждый черновик подзадача `action: item`, `run` пишет один материал.
- `topic`: один материал на тему (`meta.topic`; префикс «карусель», «пост», «история», «рилс» или `meta.type` выбирают тип, иначе рилс).
- `profile`: разовый пакет настройки профиля (био до 150 знаков, 5 «Актуальных» с названием и обложкой, 3 идеи закрепов, текст ссылки,
  порядок первой недели). Тип материала `profile`, одно одобрение. Это старт-кит: разделы Instagram, YouTube (описание, плейлисты, баннер 2560x1440 с безопасной зоной 1546x423, 5 Shorts) и TikTok (био до 80 знаков, 3 видео, 5 наборов хештегов), по запросу на каждый раздел (`prompts/profile*.md`), текст разделён маркерами `## Платформа`, область задаёт `topicKey` (`profile:setup` или `profile:<платформа>`).
- `article`: статья блога сайта (см. ниже).
- `meta.feedback`: переделка с учётом замечаний ревью (сгенерированный текст приходит в промпт как «отклонённый»).

Типы материалов (`ItemType`): `clip` (рилс, Instagram + TikTok + Shorts), `carousel`, `post` (заголовок до 60 знаков, 1-2 строки на картинке,
подпись 300-900 знаков с призывом к @firtech_bot или firtech.pro, до 5 хэштегов), `story` (3-5 кадров, последний призыв, строка «Куда ведёт»),
`profile`. Для постов, историй и профиля цен нет совсем (`lintText(..., { noPrices: true })`), стоп-фразы, «не X, а Y» и длинные тире ловит та же проверка.

Генерация: строгий JSON через `tryJson` + схема (`format.ts`), проверка тона (`lint.ts`), один автоисправлённый заход
(`generate.ts`). Остаток замечаний идёт владельцу предупреждением над материалом.

## Картинки (`render.ts`)
`satori` (разметка в SVG) + `@resvg/resvg-js` (SVG в PNG), чистый Node без Chromium, системные шрифты не нужны (`loadSystemFonts: false`).
Размеры: пост и слайд 1080x1350, история и обложка Актуального 1080x1920. Бренд: фон `#0a0d0b`, белый текст, лайм `#b5eb6a` (токены сайта),
вордмарк «fir.tech» с лаймовой точкой слева внизу, заголовки Unbounded Bold, текст Onest (`assets/fonts`, оба OFL; Onest из `@fontsource/onest`,
кириллица и латиница отдельными файлами `OnestLatin`). `framesOf(type, text)` разбирает кадры из утверждённого текста (после правки владельца тоже),
`renderItem(dir, itemId, type, text)` пишет `<dir>/<itemId>/<n>.png`. Рисует `kindSpec().execute` сразу после одобрения (`rendersDir`, в HQ это
`DATA_DIR/renders`); пути лежат в `cm_ready.files` строки Instagram. Сбой рендера не блокирует одобрение: материал остаётся готовым без файлов,
Публикатор пишет «Картинки не созданы». Проверено на plain Node (`pnpm --filter hq --prod deploy`), образ `node:22-bookworm-slim`.

## Статьи блога (`article.ts`, таблица `cm_articles`)
`action: article`, одна статья в день (рутина HQ `marketing-article-daily`). Линия: `meta.line` (`ai` или `niche`; голова считает её по дню недели на часах владельца: пн, ср, пт, вс `ai`, вт, чт, сб `niche`), `meta.niche` (id,
кусок названия или «ии») её перекрывает; `meta.articleId` + `meta.feedback`: переделка той же строки. `ai`: «ИИ для бизнеса», тема из `AI_TOPICS` (`topics.ts`), не повторяется 60 дней, подсказки Трендвотчера в промпте
(`prompts/article-ai-ru.md`, `article-ai-en.md`). `niche`: ниша, которой не было 60 дней (`recentArticleTopics`). Использованные темы лежат в `cm_articles.topic_key`.
Две генерации: русский текст (700-1200 слов), затем английская версия по нему (600-1300), оба строгим JSON формата сайта
(`firtech/src/content/blog/types.ts`: блоки `p`, `h2`, `list`, `callout`, `cta`; описание 120-160 знаков; FAQ из 3 вопросов; без длинных тире,
без сумм в долларах и процентов, цену называет конструктор). Таблица ниш: `niches.ts`, зеркало каталога конструктора сайта (56 ниш, 10 категорий,
10 продуктов), правится вручную. Одобрение `article` (уровень 0, `locked`) регистрирует голова и вызывает `approveArticle`: `published = 1`, `date` = день одобрения, slug из английского заголовка
(`slugFromTitle`, `uniqueSlug`: ASCII kebab-case, числовой суффикс при совпадении), статья ждёт следующего пакета (`pack_queued`). `toPublicArticle` даёт форму `Article` сайта для `GET /blog`.
Повторное использование: `plan()` пакета берёт ждущие статьи, на каждую одну карусель и один рилс (`cm_items.source_slug`, промпт получает `articleSource`: заголовок, h2, первый абзац).

## Одобрение
Тип `content_item` (`worker.kindSpec`): уровень 0 и `locked`, счётчик доверия автопубликацию не включает. После
«Одобрить» `onApproved` пишет в `cm_ready` по строке на платформу (клип: Instagram, TikTok, Shorts; карусель: Instagram)
с плановой датой (пост, история и профиль: одна строка Instagram), затем рисует PNG (см. выше). Правка по частям: `editableParts`, `partLabel`, `replacePart` (кнопки и сообщения делает голова).
Хелперы для отчётов: `todayReport(store, date)`, `queueText`, `statsText`.

## Переменные (задаёт `apps/hq`)
`CLIPS_PER_WEEK` (7), `CAROUSELS_PER_WEEK` (2), `POSTS_PER_WEEK` (3), `STORIES_PER_WEEK` (5). Промпты в `prompts/*.md` (русский, голос бренда), входят в пакет.

## Видео рилса (этап 2)
`parseReel(text)` читает одобренный текст клипа (хук, сцены «Голос/Субтитр», CTA, секунды, язык). `RenderQueue` (`render-queue.ts`, таблица
`cm_render_jobs`): `enqueue` при одобрении, `claim` одной задачи, до 2 попыток, `requeue` для `/render`. Видео собирает сервис `packages/renderer`
(Remotion, голос Piper), результат `DATA_DIR/renders/<материал>/reel.mp4`. Картинки постов, каруселей и историй рисуются здесь (см. выше).


## Цены
`src/directions.ts` хранит названия направлений и описания; суммы берутся из прайс-листа сайта (`getPrices()` из `@fir/core`) в момент использования. Линт принимает любую сумму из прайс-листа (продукты, тарифы, каталог, допы) и бракует остальные, в том числе старые.

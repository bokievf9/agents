# @fir/worker-lead-intake: Приёмщик лидов (исполнитель отдела продаж)

Бывший `apps/lead-intake`: логика заявки (классификация, карточка, первый ответ, слоты) без бота, крона и HTTP.
Webhook `POST /lead` живёт в `apps/hq/src/webhook.ts` и создаёт задачу отдела с `meta.lead` (поля формы firtech.pro).

`LeadIntakeWorker.run(task, ctx)`, действие `lead`: ниша, задача и срок (LLM `tryJson`, без LLM эвристики `text.ts`), температура
по правилам (`scoreLead`), слот из формы или два ближайших рабочих дня в `slotHours` (по умолчанию 11:00 и 15:00),
карточка лида, черновик первого ответа (модель пишет без цифр и со слотами, иначе шаблон RU/EN). Вопрос о цене даёт
отдельное предложение `lead_price` (`locked`, уровень 0, метки [цена] / [срок], с меткой наружу не уходит). Первый ответ:
`lead_reply` (старт на `replyLevel`, по умолчанию 1, обычный счётчик доверия). Одна задача, один лид (`li_leads.task_id`):
переделка по ревью не плодит строки. Что не переехало: Telegram-диалог с клиентом (3 вопроса) и экспорт `leads.jsonl`.

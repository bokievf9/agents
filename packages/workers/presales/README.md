# @fir/worker-presales

Пресейл: лид (`li_leads`) или текст владельца в КП, смету и черновик договора (Markdown, русский, `ps_documents`).
Цены только из прайс-листа сайта (`getPrices()` из `@fir/core`, названия и сроки в `src/offers.ts`), оплата по этапам и способы USDT TRC20/TON или кошелёк из сметы; модель пишет формулировки с метками `[цена]` и `[срок]`, шаблоны `templates/*.md` их подставляют.
Одно одобрение `presales_pack` (уровень 0, locked). Оплата по этапам (`stagesFor` из `@fir/core`, пакет несёт `stages`). Настройки: `KP_VALID_DAYS` (передаёт `apps/hq`).
Запускается само, когда лид стал квалифицированным (есть услуга и бюджет или смета конструктора, `isQualified` в `apps/hq/src/heads/sales.ts`), и вручную `/kp`.
**Точные цифры (решение владельца 2026-11-19).** КП, смета и договор называют одну точную цену выбранного пакета, без «от»: `src/package.ts` (`quotePackage`) берёт её из прайс-листа сайта. Сайт: вариант каталога плюс допы,
которые названы в заявке или в сводке конструктора (по умолчанию лендинг), каждая строка отдельно, итог их сумма. Остальные продукты: цена стандартного пакета с сайта (`products`, у сайта это сумма его частей). Подписки (контент, агент): настройка и точная
месячная плата. Итог из конструктора клиента (`estimate` лида) только сверяется и даёт предупреждение на карточке, ценой не становится: форма публичная. «От» остаётся в сообщениях Разведчика и клиентского бота, где состав ещё неизвестен.
Во все три документа и в счёт идёт одна строка условий: «Домен, хостинг, сервер и платные сторонние сервисы (SMS, API, платежи) в сумму не входят...» (`costsLine` в `@fir/core`); если у клиента уже есть домен и/или хостинг
(`li_leads.has_domain`, `has_hosting`: ответ на шаг 4 бота, предложение сайта в сводке или слова в заявке), строка короче. Сроки остаются диапазонами из `offers.ts` (решение владельца, COMPANY.md).
В данных одобрения лежат числа для цепочки продаж: `totalUsd` (точная цена пакета), `monthlyUsd` (если есть), `stages`, `prepayUsd` и `prepayPercent` (первый этап), `direction`, `hasDomain`, `hasHosting`. После «Утвердить» голова продаж резервирует проект, Бэк-офис готовит договор,
Сопровождение счёт на предоплату (см. `apps/hq/README.md`, «Цепочка продаж»).
Тесты: `pnpm --filter @fir/worker-presales test`.

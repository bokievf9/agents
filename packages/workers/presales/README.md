# @fir/worker-presales

Пресейл: лид (`li_leads`) или текст владельца в КП, смету и черновик договора (Markdown, русский, `ps_documents`).
Цены только из прайс-листа сайта (`getPrices()` из `@fir/core`, названия и сроки в `src/offers.ts`), оплата 50/50 и способы USDT TRC20/TON или кошелёк из сметы; модель пишет формулировки с метками `[цена]` и `[срок]`, шаблоны `templates/*.md` их подставляют.
Одно одобрение `presales_pack` (уровень 0, locked). Настройки: `PREPAYMENT_PERCENT`, `KP_VALID_DAYS` (передаёт `apps/hq`).
Запускается само, когда лид стал квалифицированным (есть услуга и бюджет или смета конструктора, `isQualified` в `apps/hq/src/heads/sales.ts`), и вручную `/kp`.
В данных одобрения лежат числа для цепочки продаж: `totalUsd` (базовая цена направления), `prepayUsd`, `prepayPercent`, `direction`. После «Утвердить» голова продаж резервирует проект, Бэк-офис готовит договор,
Сопровождение счёт на предоплату (см. `apps/hq/README.md`, «Цепочка продаж»).
Тесты: `pnpm --filter @fir/worker-presales test`.
